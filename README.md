Aplicação web desenvolvida em Python para geração de senhas seguras, com interface moderna, interativa e personalizável.

---
Sobre o Projeto
Este projeto foi desenvolvido em Python com testes automatizados e uso de IA generativa na criação de testes.

Tela principal

### 🔐 Gerando senha
Gerar senha

---

## ✨ Funcionalidades

- 🔐 Geração de senhas seguras
- 🎚️ Controle de tamanho da senha (mínimo 6 caracteres)
- ☑️ Seleção de tipos de caracteres:
 - Letras minúsculas  
 - Letras maiúsculas  
 - Números  
 - Símbolos  
- 👁️ Mostrar/ocultar senha
- 📋 Copiar senha com um clique
- 💜 Interface moderna com tema lilás
- 🖼️ Imagem de fundo personalizada com opacidade

## ⚙️ Como executar o projeto

### 1. Clonar o repositório
bash git clone <seu-repositorio> cd gerador_senhas 

---

### 2. Instalar dependências
bash pip install -r requirements.txt 

---

### 3. Executar a aplicação
bash python app.py 

---

### 4. Acessar no navegador
http://127.0.0.1:5000

---

## 🧪 Testes automatizados

O projeto conta com testes automatizados usando Selenium.

### Executar testes:

1. Inicie a aplicação:
bash python app.py 

2. Em outro terminal:
bash python test_senha.py
